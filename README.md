# Calculadora en Java Swing

¡Bienvenido/a! Este proyecto es una aplicación de escritorio gráfica (GUI) desarrollada en Java que permite realizar operaciones matemáticas básicas.

---

## CARACTERISTICAS
* Operaciones básicas: Suma, resta, multiplicación y división.
* Soporte de entrada por teclado: Permite escribir números y operadores directamente desde el teclado, así como usar la tecla `Enter` para calcular y `Esc` / `Delete` para borrar.
* Formateo inteligente de decimales: Limita el resultado a un máximo de 4 decimales.


## DESARROLLO EN

- Lenguaje: Java (JDK 8+)
- Interfaz: Java Swing / AWT
- IDE: NetBeans.
